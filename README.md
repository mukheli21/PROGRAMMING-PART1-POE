# ChatApp

## PROG5121 Programming-part1-poe

This project is a Java console-based ChatApp application developed for Programming 

## Part 1: Registration and Login

The first part of the project focuses on creating a registration and login system.

The application includes:
- Username validation
- Password complexity validation
- Cell phone number validation
- User registration
- User login
- JUnit unit testing

## Technologies Used

- Java
- NetBeans
- Maven
- JUnit
- Git and GitHub
