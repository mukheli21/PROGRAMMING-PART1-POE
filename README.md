# ChatApp

## PROG5121 Programming-Part1-POE

This project is a Java console-based ChatApp application developed for Programming.

## Part 1: Registration and Login

The first part of the project focuses on creating a registration and login system.

The application includes:

- Username validation
- Password complexity validation
- Cell phone number validation
- User registration
- User login
- Interface-based design (`IUserValidation` interface implemented by the `Login` class)
- Storage of registered user details in an array
- JUnit unit testing

## Validation Rules

- **Username:** must contain an underscore and be no more than 5 characters
- **Password:** minimum 8 characters, must include at least one capital letter, one number, and one special character
- **Cell number:** must include the South African international code (+27) followed by 9 digits

## Technologies Used

- Java
- NetBeans
- Maven
- JUnit

## How to Run

1. Clone the repository
2. Open the project in NetBeans
3. Run `ChatApp.java`
4. Follow the on-screen prompts to register and log in

## Testing

The project includes JUnit tests covering:

- Username validation (valid and invalid cases)
- Password complexity validation (valid and invalid cases)
- Cell phone number validation (valid and invalid cases)
- Successful and failed login attempts
- Interface implementation check
